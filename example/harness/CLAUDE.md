# CLAUDE.md

A student's workspace: one capstone, one course, one club. Made up, for the desk's setup example.

## How I work

- Every project has a folder under `projects/` with a `STATUS.md` whose first block says where it stands.
- At the end of a session, write the project's `NEXT-SESSION-PROMPT.md` so the next chat can pick it up.
- The first message of every chat runs the `session-gate` skill, which names the chat and adds a row to `sessions.md`.
